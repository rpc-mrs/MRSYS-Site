# MRSYS — сайт на Next.js + TypeScript

Три страницы: главная, каталог продукции с карточками на отдельные страницы
товаров, и контакты с формой обратной связи, отправляющей письмо по SMTP.

Заказчик: ООО НПФ «МРС», ИНН 2311292920, г. Краснодар.

## Запуск

```bash
npm install
cp .env.example .env.local   # заполните реальные SMTP-данные
npm run dev
```

Откройте http://localhost:3000

## Переменные окружения (`.env.local`)

```
SMTP_HOST=smtp.yandex.ru
SMTP_PORT=465
SMTP_USER=your-mailbox@yandex.ru
SMTP_PASSWORD=пароль-приложения
CONTACT_TO=dir@mrsys.ru   # необязательно, по умолчанию = SMTP_USER
NEXT_PUBLIC_SITE_URL=https://mrsys.ru
```

Для Yandex-почты `SMTP_PASSWORD` — это **пароль приложения**, а не обычный
пароль от ящика (создаётся в настройках безопасности Яндекс ID). Если форма
не отправляется с ошибкой `ETIMEDOUT` — это почти всегда блокировка порта
465 сетью/провайдером, а не проблема кода; попробуйте `SMTP_PORT=587`.

Никогда не коммитьте `.env.local` — он уже добавлен в `.gitignore`.

## Структура

```
src/
  app/
    page.tsx                 — главная страница
    products/page.tsx        — каталог продукции
    products/[slug]/page.tsx — страница отдельного товара
    contacts/page.tsx        — контакты + форма
    api/send-email/route.ts  — обработчик формы (nodemailer)
    sitemap.ts                — генерация /sitemap.xml
    robots.ts                 — генерация /robots.txt
  lib/
    products.ts               — данные о товарах (название, описание,
                                 характеристики, изображения, видео)
    site.ts                   — базовый URL сайта для SEO-тегов
  components/                 — Header, Footer, ProductCard, Waveform (SVG)
public/images/                — фотографии товаров
```

## Добавление товара

Добавьте объект в массив `products` в `src/lib/products.ts` — страница
`/products/<slug>` создастся автоматически, вместе со строкой в sitemap.xml.

## Что ещё нужно доделать перед публикацией

- **Реальные фотографии** — сейчас на месте фото плейсхолдер-блок с
  подписью. Положите файлы в `public/images/` (пути уже прописаны в
  `lib/products.ts`) и замените блок-плейсхолдер в `ProductCard.tsx` и
  `app/products/[slug]/page.tsx` на `<img>`.
- **Видео**, если есть — добавьте `videoUrl` (ссылка на embed с YouTube/
  RuTube) в нужный товар в `lib/products.ts`, он подхватится автоматически.
- **Точные характеристики термостата** — модель, диапазон и точность
  поддержания температуры, число мест под пробы. Текущее описание намеренно
  без конкретных цифр, которых я не смог подтвердить.

## Форма обратной связи

- Скрытое поле `alias` — honeypot против ботов: реальные пользователи его
  не видят и не заполняют; если оно пришло непустым, письмо не отправляется,
  но пользователю показывается «успех», чтобы не подсказывать боту.
- Обязательные поля: имя, email, сообщение. Телефон — опционален.
- При отправке письмо уходит на `CONTACT_TO` (или `SMTP_USER`), с `replyTo`,
  указывающим на email отправителя, чтобы отвечать можно было прямо на
  письмо.

## SEO

Технически на сайте уже настроено:

- `src/app/sitemap.ts` → отдаёт `/sitemap.xml` со всеми страницами
  (обновляется автоматически при добавлении товара в `lib/products.ts`).
- `src/app/robots.ts` → отдаёт `/robots.txt`, разрешает индексацию,
  закрывает `/api/`, указывает на sitemap.
- Заголовки, описания и `keywords` под каждую страницу — используют
  целевые фразы вроде «ЯМР-анализатор», «АКС-2020», «термостат».
- Canonical-ссылки и Open Graph теги на каждой странице.
- JSON-LD структурированные данные: `Organization` (с ИНН и юр. названием)
  в layout, `Product` на каждой странице товара.
- Обязательно задайте `NEXT_PUBLIC_SITE_URL` в `.env.local` — от него
  строятся sitemap, robots.txt и canonical-ссылки.

Дальше нужны шаги вне кода — без них техническая часть не даст результата:

1. **Зарегистрируйте сайт в Яндекс.Вебмастере и Google Search Console**,
   подтвердите права (мета-тег из `verification` в `app/layout.tsx`) и
   отправьте `sitemap.xml` на переобход.
2. **Добавьте реальные фото и alt-тексты** — `alt` в `product.images` уже
   прописан, просто подставьте файлы в `public/images/`.
3. **Наращивайте ссылки на сайт** — из профилей на отраслевых площадках
   (Яндекс.Бизнес, 2ГИС, каталоги оборудования), из статей и упоминаний —
   это сильнее всего влияет на позиции по коммерческим запросам вроде
   «купить ЯМР-анализатор».
4. Позиции по «АКС-2020» и «термостат» появятся быстрее, чем по общему
   «ЯМР-анализатор» — это узкие, низкочастотные запросы с почти нулевой
   конкуренцией, где страницы товаров и так неплохо ранжируются за счёт
   точного соответствия названию в `<title>` и `<h1>`.
